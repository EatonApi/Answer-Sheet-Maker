# AnswerSheetStudio 答题卡制作

> 所见即所得的答题卡设计工具，适用于中小学 / 考试机构自制机读答题卡。
> 基于 **WPF + .NET 10** 开发，**零第三方依赖**，PDF 导出为手写实现。

---

## 简介

AnswerSheetStudio 是一款面向"印刷 + 阅卷机识别"场景的答题卡排版工具。
所有版面以**毫米**为单位精确控制，所见即所得——设计界面、打印稿、导出 PDF / PNG
三者完全一致。支持 A4 与 A3（A3 可双栏 / 三栏）纸张、多种答题模块、单题跨页续排、
作文续排、逐题自定义，以及打印、导出 PDF、导出 PNG。

---

## 功能特性

### 版面与纸张
- 纸张：A4（锁定单栏）、A3（可选双栏 / 三栏）。
- 「面」= 整张纸的一面；一张纸按 正面各栏 → 反面 → 下一张纸 的顺序排版。
- 标题与考生信息栏仅出现在每张纸**正面第一栏**上方。
- 每印刷面独立绘制一套装饰：四角定位点、面标识（`CombinedBoxes` / `MovingDots`）、
  页眉、页脚。
- 支持占位符：`{面}/{总面}`、`{页}/{总页}`、`{栏}/{总栏}`。

### 模块类型
- **选择题**：横排 / 竖排、选项横排并排或竖排堆叠、竖排多列（列优先）、逐题选项数、
  逐题小题号；填涂样式可选字面中括号 `[A]` 或方框。
- **填空题**：支持一行多空、窄栏自动收敛列数、逐题小题号。
- **解答题**：逐题高度、题号后显示分数（格式可调）、引导线（题号与首条横线同行 /
  可选版式、实线 / 虚线 / 颜色可调）；支持**单题跨页**，续排处标注「N题续」。
- **作文区**：方格稿纸 / 实线横线 / 英语实线横线；续排页不重复标题或「（续）」标识；
  方格稿纸支持字数刻度（100 / 200 …）。
- **考号区**：标题行 + 手写数字行 + 填涂数字网格；可单独设定尺寸；
  支持字段区与网格**右置并排**。
- **非作答区**：文字 / 背景 / 边框三色 + 实线 / 虚线 / 无边框 + 45° 斜线阴影。
- **图片插图**：在答题卡中插入用户提供的图片（Logo / 相片等）。
- **自定义模块**：自由文本与框线区域。

### 填涂与样式
- 填涂尺寸来源：跟随「全卷填涂样式」模板，或本模块单独设定。
- 选择题与考号区可分别选择不同字体、字号与填涂样式。
- 框线三级颜色（框线 / 大外框 / 小题框）与多种线型（实线 / 虚线）。

### 导出与打印
- **打印**：直接调用系统打印，请选择「实际大小 / 100%」。
- **导出 PDF**：手写 PDF 1.4，零依赖；默认 300 DPI（150–600 可调），每面一页。
- **导出 PNG**：每面一张位图，便于预览与分享。

### 交互与体验
- 启动引导页：新建项目 / 打开原有项目 / 历史项目列表，可设置「启动时不再显示」。
- 最近项目记录、未保存保护（关闭 / 新建 / 打开均有「是 / 否 / 取消」确认）。
- 预览区支持缩放、适应宽度、上 / 下页切换，以及**拖拽直接调整区域大小**。

## 构建与运行

前置要求：安装 **.NET 10 桌面运行时 / SDK**（含 WPF 支持，Windows）。

```bash
# 进入项目目录
cd AnswerSheetStudio

# 发布（Release）
dotnet build -c Release

# 直接运行
dotnet run -c Release
```

构建产物位于 `AnswerSheetStudio/bin/Release/net10.0-windows/`。
若需把程序复制给本机其他位置使用，请连同以下文件一起复制：
`AnswerSheetStudio.exe`、`AnswerSheetStudio.dll`、`AnswerSheetStudio.deps.json`、
`AnswerSheetStudio.runtimeconfig.json`、`AnswerSheetStudio.pdb`。

## 使用说明（简要）

1. 启动后通过引导页**新建项目**：填写标题、选择纸张（A4 / A3 及栏数）、
   设定保存位置与文件名。
2. 在左侧模块列表添加所需模块（选择题、填空题、解答题、作文区、考号区等），
   右侧属性面板逐项调整尺寸、字体、颜色、线型等。
3. 拖动预览区中的区域手柄可直观调整大小；工具栏可缩放、翻页、切换辅助线 / 拖拽。
4. 完成后通过工具栏 **打印**（选「实际大小」）或 **导出 PDF / PNG**。
